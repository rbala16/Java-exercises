# ⬆️ Super Keyword

## Definition

super refers to the parent class.

## Uses

### Call Parent Constructor

```java
super(first, last);
```

### Call Parent Method

```java
super.showName();
```

## Diagram

```text
Person
   ▲
   │
Student
```

## Interview Notes

- Must be first statement in constructor.
- Used when child needs parent initialization.
